# 🚀 IT Analytics & Web Development Platform

Мой личный проект, представляющий собой современное веб-приложение (landing page) в сфере IT-аналитики и разработки. Проект создан для демонстрации навыков адаптивной верстки, работы с компонентной структурой и интеграции современных UI-решений.

---

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3
* **Styling:** Tailwind CSS (библиотека утилитарных классов для быстрой и гибкой стилизации)
* **Верстка:** Flexbox, Grid Layout (полная адаптивность под любые экраны)
* **Version Control:** Git & GitHub

---

## 🌟 Ключевые особенности проекта

* **Адаптивный дизайн:** Сайт идеально отображается как на экранах 4K мониторов, так и на мобильных устройствах.
* **Современный UI/UX:** Минималистичный темный интерфейс с акцентными цветами, плавными переходами и четкой структурой.
* **Многостраничная навигация:** Реализована структура разделов (Главная, Сервисы, Карьера, Контакты) для полноценного пользовательского опыта.
* **Оптимизация:** Чистый код без лишних стилей благодаря использованию Tailwind CSS.

---

## 📂 Структура проекта

* `index.html` — Главная страница проекта.
* `page2.html` — Раздел "Services" (Услуги и аналитика).
* `page3.html` — Раздел "Careers" (Вакансии и команда).
* `page4.html` — Подробное описание карьерных возможностей.
* `page5.html` — Форма обратной связи и контакты.
* `/assets` или `/img` — Папка с графическими материалами и иконками.
